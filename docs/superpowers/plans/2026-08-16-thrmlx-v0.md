# thrmlx v0.1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:subagent-driven-development`
> (recommended for independent tasks) or `superpowers:executing-plans` to execute this plan.

**Goal:** Ship a public, Apache-2.0 Python package that samples pairwise Ising models with MLX
on local Apple Silicon and is statistically correct against exact enumeration.

**Architecture:** `Ising` is the deep model module: it owns dense parameter validation,
deterministic graph coloring, reduced-energy semantics, and immutable block metadata. `sample` is
the sole execution seam: it owns state preparation, explicit-key random draws, ordered block-Gibbs
sweeps, schedule timing, clamping, and batched output. The public interface remains array-native
and does not expose THRML's JAX graph/program machinery.

**Tech Stack:** Python 3.10+, MLX 0.32, uv/uv_build, pytest, pytest-xdist, Ruff, ty, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-08-16-thrmlx-v0-design.md`

## Global constraints

- Use `apply_patch` for hand-authored file changes and `uv` for every Python environment command.
- Keep imports at file tops, use `pathlib.Path` for paths, and do not add threads,
  multiprocessing, `to_thread`, global random seeding, or unnecessary exception branches.
- Preserve the reduced-energy convention `-beta * (b @ s + 0.5 * s.T @ J @ s)`.
- Implement behavior test-first. Observe each focused test fail for the intended missing behavior
  before writing the production code that makes it pass.
- Keep setup reversible: every documented local setup command points to the scoped teardown script.
- Commit after each complete task. Verify committed content, not only tool exit status.
